## About This Repository

This repository contains practical assignments and implementations completed as part of the Computer Graphics Lab course.

The practicals focus on understanding the fundamentals of computer graphics through C++ programming. They involve working with graphical libraries, coordinate systems, geometric shapes, pixel plotting, and graphics algorithms.

Each lab assignment is maintained separately with its source code, output images, and supporting documentation wherever applicable.

## Practical Assignments

| Lab | Topic | Description |
|---|---|---|
| Lab 1 | Basic Geometric Shapes | Drawing a line, circle, rectangle, and triangle using `graphics.h`. |
| Lab 2 | DDA Line Drawing Algorithm | Generating a line between two points using the DDA algorithm. |

## Key Learning Areas

Through these practical assignments, the repository explores:

- Fundamentals of computer graphics.
- Graphics initialization and screen coordinates.
- Geometric shape construction.
- Pixel plotting and coordinate calculations.
- Line drawing algorithms.
- Implementation of graphics functions in C++.

## Purpose of This Repository

The objective is to build practical knowledge of computer graphics by implementing algorithms, understanding their working procedures, and observing their graphical outputs.
